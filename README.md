# PHP projects

PHP projects by [GonService](https://gonserviceit.com.br/software-sob-demanda): modern PHP 8,
containers and CI, including the path from a legacy system to a maintainable one. Each folder is an
independent project with its own README and tests.

| Project | What it shows | Stack |
| --- | --- | --- |
| [laravel-docker-starter](laravel-docker-starter) | Laravel 12 running like production: Nginx, PHP-FPM, MySQL, health checks, tested API and a CI smoke test | Laravel, PHP 8.3, Docker |
| [php-mini-crm](php-mini-crm) | Small CRM for a service company: customers with CPF/CNPJ check-digit validation, interaction timeline, overdue follow-ups, search and login | PHP 8.3, SQLite, no framework |
| [php-contact-form](php-contact-form) | Secure contact form: validation, CSRF, honeypot, per-IP rate limit, messages stored before optional SMTP, password-protected inbox | PHP 8.3, SQLite, SMTP |
| [php-products-api](php-products-api) | REST JSON API for a product catalog: CRUD, 422 validation errors, pagination, filters, sorting, API keys, ETags and OpenAPI 3 | PHP 8.3, SQLite, OpenAPI |
| [php-legacy-modernization](php-legacy-modernization) | A vulnerable legacy page and the same feature refactored, with tests proving SQL injection, XSS and CSRF are gone | PHP 8.3, PDO, refactoring |
